# Politique de sécurité

## Signaler une vulnérabilité

**N'ouvrez pas de ticket public.** Écrivez à : `<CONTACT SÉCURITÉ À COMPLÉTER>`
(clé OpenPGP : `<EMPREINTE À COMPLÉTER>`).

Indiquez si possible :

- la version ou le commit concerné ;
- le composant (core, agent passerelle, portail, coffre-fort, outil `ostena-verify`…) ;
- une description de l'impact et les étapes pour reproduire ;
- vos coordonnées, et si vous souhaitez être crédité.

## Divulgation coordonnée

- Accusé de réception sous **5 jours ouvrés**.
- Première évaluation (recevabilité, gravité CVSS) sous **15 jours ouvrés**.
- Correctif et publication coordonnés avec vous ; délai cible de **90 jours** maximum entre le signalement et la divulgation publique, ajustable d'un commun accord.
- Une CVE est demandée pour toute vulnérabilité confirmée.

Nous ne poursuivrons pas les chercheurs qui agissent de bonne foi, dans le respect de cette politique, sans accéder à des données qui ne leur appartiennent pas ni dégrader de service.
