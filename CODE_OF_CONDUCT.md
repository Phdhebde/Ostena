# Code de conduite

Ostena adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/) ([texte original](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).

En résumé : nous voulons que la participation au projet soit une expérience sans harcèlement pour tous, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, la religion ou l'orientation sexuelle. On critique des idées et du code, jamais des personnes. Les attaques personnelles, le harcèlement et la publication d'informations privées d'autrui sont exclus.

Ce code s'applique dans tous les espaces du projet (tickets, pull requests, discussions) et lorsqu'une personne représente le projet ailleurs.

## Signaler un comportement

Contactez un mainteneur, [@Phdhebde](https://github.com/Phdhebde), ou utilisez la fonction **Report content** de GitHub sur le message concerné. Les signalements sont traités avec discrétion, et les mesures suivent les [lignes directrices d'application](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/#lignes-directrices-dapplication) du Contributor Covenant : correction, avertissement, exclusion temporaire, puis définitive.
